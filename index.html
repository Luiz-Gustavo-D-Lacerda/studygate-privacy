Política de Privacidade

StudyGate — Última atualização: 24 de junho de 2026

Esta Política de Privacidade descreve como o aplicativo StudyGate, desenvolvido por Luiz Gustavo Domingues Lacerda, coleta, usa e protege suas informações. Ao utilizar o aplicativo, você concorda com as práticas descritas neste documento.

1. Informações que coletamos

  • Dados de conta: endereço de e-mail, nome de exibição e identificador único de usuário (UID), fornecidos pelo Google Sign-In ou gerados anonimamente pelo Firebase Authentication.
  • Perfil de estudo: curso, semestre, áreas de estudo, modo de intensidade e configurações de dificuldade que você define no app.
  • Progresso e histórico: questões respondidas, pontuação XP, sequências de estudo (streaks) e datas de revisão agendadas pelo sistema de repetição espaçada (SRS). Esses dados são armazenados localmente no dispositivo via Hive.
  • Dados de assinatura e compras: histórico de transações e status do plano (Free, Trial, Essencial ou Pro), processados pelo RevenueCat. Não armazenamos dados de cartão de crédito; esses dados são gerenciados exclusivamente pela Apple App Store / Google Play.
  • Dados de desempenho e falhas: em caso de erro ou instabilidade, dados técnicos anônimos (stack trace, versão do app, versão do SO, modelo do dispositivo) são enviados ao Firebase Crashlytics para diagnóstico.
  • Dados de verificação de integridade: o Firebase App Check valida que o tráfego origina-se de instâncias legítimas do app (sem coleta de dados pessoais adicionais).
  • Interações com o produto: padrões de uso agregados e anônimos para melhoria contínua do app.
  • Aplicativos bloqueados: a lista de apps que você escolhe bloquear é armazenada exclusivamente no dispositivo e nunca é transmitida a servidores externos.

2. Como usamos suas informações

  • Gerar questões de estudo personalizadas por meio de modelos de inteligência artificial.
  • Calcular o agendamento de revisão espaçada (SRS) para maximizar sua retenção de conteúdo.
  • Gerenciar o status da sua assinatura e aplicar os limites de uso de cada plano.
  • Identificar, diagnosticar e corrigir falhas técnicas no aplicativo.
  • Enviar notificações locais de revisão diária (somente no dispositivo, sem servidores de push).
  • Melhorar a experiência de uso com base em dados agregados e anônimos.

3. Terceiros que processam seus dados

Não vendemos, alugamos nem compartilhamos seus dados pessoais com terceiros para fins comerciais. Os serviços de terceiros utilizados são:

  • Google Firebase (autenticação, relatórios de falhas, verificação de integridade) — Política do Firebase
  • Google Sign-In (login com conta Google) — Política do Google
  • RevenueCat (gerenciamento de assinaturas e compras in-app) — Política do RevenueCat
  • Anthropic / Claude API (geração de questões via IA) — o contexto de estudo é enviado para gerar questões; nenhum dado pessoal identificável é incluído nos prompts.
  • Google / Gemini API (geração de questões via IA, planos Free e Trial) — Política do Google
  • OpenAI / GPT API (geração de questões via IA, como fallback) — Política da OpenAI

4. Armazenamento e segurança

A maior parte dos dados (histórico de questões, configurações, progresso) é armazenada localmente no seu dispositivo com criptografia AES-256 via Hive. Dados de autenticação são gerenciados pelo Firebase Authentication com transmissão protegida por TLS. Adotamos medidas técnicas razoáveis para proteger suas informações contra acesso não autorizado.

5. Retenção de dados

Os dados locais permanecem no dispositivo até que você desinstale o aplicativo ou exclua sua conta. Dados de autenticação e assinatura no Firebase e RevenueCat são excluídos mediante solicitação formal (ver seção 8).

6. Privacidade de menores

O StudyGate é destinado a estudantes do ensino superior (maiores de 13 anos). Não coletamos intencionalmente informações de crianças menores de 13 anos. Se você acredita que uma criança forneceu dados pessoais, entre em contato conosco para remoção imediata.

7. Seus direitos

  • Acessar, corrigir ou excluir seus dados pessoais.
  • Revogar o acesso do Google Sign-In a qualquer momento nas configurações da conta Google.
  • Solicitar a portabilidade dos seus dados.
  • Cancelar sua assinatura a qualquer momento (ver Termos de Uso para instruções).
  • Solicitar a exclusão completa da sua conta e de todos os dados associados.

8. Exclusão de dados

Você pode solicitar a exclusão completa dos seus dados pessoais de duas formas:

  • Pelo aplicativo: acesse Perfil → Deletar minha conta. A exclusão remove imediatamente sua conta e todos os dados associados nos nossos servidores.
  • Por e-mail: envie uma solicitação para lacerdadomingues1@gmail.com com o assunto "Exclusão de dados". Atenderemos seu pedido em até 30 dias.

9. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. A data de revisão no topo da página será atualizada a cada alteração. O uso continuado do aplicativo após alterações constitui aceitação da política revisada.
